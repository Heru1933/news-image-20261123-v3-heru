THE MONDAY WIRE — a broadsheet of Monday 23 November 2026. 40 stories,
all verified against Reuters, AP, BBC, ESPN, Sky Sports and others, each
with its source printed beside it. Pure Python standard library renderer
(no Pillow): bitmap fonts, a raw-RGB still blitter, a small canvas and a
PNG encoder. Warm paper, ink text, red rules: a masthead naming the day,
four heroes in a 2x2 grid each with its toon illustration, THE DAY IN
BRIEF (12 more stories in three columns), stories 17-40 as a numbered
list, and a stats strip (+31.5% Nvidia, 0 COP31 deal, 24 dead in the Java
factory fire, 258 Democrat House seats, 153 drones overnight, $44BN cyber
deal). Fully deterministic — two runs write byte-identical PNGs.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `output/`.
